## 三条使用纪律

**① 已闭合的条目不删。** 它们记着这条债当初是怎么关掉的,而那正是同类债再次出现时最有用的东西。
✅ 删除线 + 保留原文,是本项目既定写法。

**② 「登记残缺」≠「遗漏」。** 划外项在 journal 原文里都写明了判据(为什么现在不做)。
判断一条是否该做,先回 journal 读判据,别只看本目录的一句话摘要。

**③ ⚠️ 注意 [`02-deferred-scope.md`](02-deferred-scope.md) §5「会静默引爆的」。**
那一族现在不可达所以不报错,前置一旦接上就**照旧走错分支且没有任何东西会红** ——
它们是本目录里唯一需要主动盯的。
