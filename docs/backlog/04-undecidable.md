### 10.1 R-b:无解的结构性事实

没有原版运行基准时，源码推定不能自动升级为运行时事实。可以用源码表达式、数据字段和初始化常量做自动核验，但这些证据各有范围。共享规则回归与实际调用链验证仍须保留。

### 10.2 旧六项的当前证据状态

| 项 | 当前结论 | 既有处置 |
|---|---|---|
| B80 的装备损坏槽位算法 | SSRC80 加权、SSRC85 可均匀；仍无该 B80 函数体证据 | DR-BT6 取加权，功能尚未实现 |
| `EsCmp` 在旧标准库里的实际顺序 | 旧比较器不满足排序约定；没有旧运行环境的行为证据 | DR-BT8 按槽号稳定排序，明确标为兼容策略 |
| B80 的 `Load_PetSkillCodes` 文件 | 两代源码和原始源码压缩包均为 `./data/skillcode.txt`，资料包有同名文件；不能由此证明 B80 的实际加载路径 | DR-DT6 继续采用已有文件并记录假设 |
| `fmdplevelexp` 初始化值 | **已补证**：B80 `.data` 文件偏移 1813952，11 个 int32 与 SSRC80 的 10000 起分支逐项一致 | DR-DT2 获得资料包层面的数据实证；家族功能未新增 |
| B80 的战斗金币公式 | 配置为 10，SSRC85 每场固定相加；B80 的计算方式仍缺证据 | DR-EC6 既有选择为每场 +10，功能尚未实现 |
| B80 `sizeof(Char)` / 视野 20 vs 23 | 旧布局无法确证且新模型不依赖它；视野仍存在两个源码值 | DR-WM1 已选 23（广播宽度，半径 11）；保留事实未决 |

读取方法、交叉对照及文件指纹：[本轮证据](../audits/evidence/2026-09-12/unresolved-data.json)。B80 为资料包中的私服重编译产物，数据实证不等同于华义官方运行时实证。
