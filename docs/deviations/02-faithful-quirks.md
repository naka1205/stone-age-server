## 为什么照抄:两条判据

**① 玩法可观察的一律照抄。** 原版的"缺陷"若能被玩家观察到(数值、概率、rng 序列),
它就**是玩法的一部分**。改掉 = 行为分叉。

**② ★★★ 但别给照抄的源码编造「它很要紧」的理由。**
这是本项目**反复兑现三次**的纪律(纪律 ⓪,[§9.0.37](../journal/12-encounter.md) 立):

> 我倾向于把「不理解为什么这么写」补完成「它一定有理由」,**而那个理由不经检验**。

⇒ 处置:照抄没错,但注释写 **「实测等价/冗余,照抄但不声称要紧」**。
⚠️ **别给冗余分支补断言** —— 冗余的分支没有能区分它的输入。

## 2. 冗余但无可观察后果(照抄,**且不声称要紧**)

★★ 这一族是纪律 ⓪ 的主战场 —— 每一条都曾差点被我补上一个编造的理由。

| 项 | 为什么冗余 | 出处 |
|---|---|---|
| **`max(per, 0)`**(状态命中率) | 源码里**根本没有这个钳位**;而 `RAND(1,100) ≥ 1` 恒成立 ⇒ 行为等价 | [§9.0.55](../journal/15-status.md) |
| **麻痹不夹 80% 上限** | 80 上限在 `else` 分支内 ⇒ 麻痹走不到;而麻痹 `per` 恒 20 ⇒ 无可观察后果 | [§9.0.55](../journal/15-status.md) |
| **`wr[i] != 0`**(编组权重) | 权重 0 不让 `acc` 增长 ⇒「选中它」等价于前一轮已 `break`;`i == 0` 要求 `r < 0` 而 `r >= 0` 恒成立 ⇒ **冗余**。★ 穷举 2,580 组证明 | [§9.0.37](../journal/12-encounter.md) |
| **抽签上界 `found - 1`** | 与 `found` 写法 0 条转红 ⇒ 等价写法 | [§9.0.37](../journal/12-encounter.md) |
| **`bigcnt >= 5` 门** | ★ 与「i>4 无 NORMAL 可换」在 **out 层面等效** —— 单靠 size 0 转红,唯一独立后果是 **rng 取数次数**(补 `calls()` 断言才转红) | [§9.0.39](../journal/12-encounter.md) |
| **`cep` 累积 `cep++`** | 在**战斗态**分支,玩家走路恒非战斗态 ⇒ 走不到;照抄源码结构但不硬接 | [§9.0.44](../journal/13-world.md) |
| **`dpbattle` 门** | 在「决斗点怪 exp=0」下无独立可观察后果(等效族第 4 次) | [§9.0.40](../journal/12-encounter.md) |
| **载入期两条归一** | 实测原版**一次都不触发**,仍然移植(判据是幂等/不耗 rng/只碰两列,不是"照抄源码") | [§9.0.35](../journal/12-encounter.md) |

## 3. ★★★ rng 序列:最隐蔽的一类「照抄」

★★ 这一族单列,因为它**返回值断言永远抓不到** —— 值对了,但之后所有随机数整体平移。

| 项 | 原版 | 若不照抄的后果 | 出处 |
|---|---|---|---|
| ★★★ **退化区间 `hi <= lo` 仍消耗一个随机数** | `RAND` 宏**无条件消耗** | 我方原写 `if (hi <= lo) return lo;` ⇒ 返回值一致、**少消耗一次** ⇒ **rng 序列自此整体平移**;★ **3,300 条断言一条都没抓到** | [§9.0.36](../journal/12-encounter.md) · `11` DR-BT23 |
| **恢复药量要摇 rng** | `UpPoint = RAND(power*0.9, power*1.1)` | 上一会话写成确定值 ⇒ 用过道具后序列平移;⚠️ **且给它补了个引着准确行号的理由** | [§9.0.53](../journal/14-item.md) · `11` DR-DT23 |
| **千分率 prob=0 时不摇** | `_FIX_ITEMPROB` ON ⇒ prob=0 直接跳过 | 摇了就多消耗一次 | [§9.0.51](../journal/14-item.md) |

⇒ ★ **这类改动唯一能拿到的正确性证据是「三处逐位一致」**
(本地 server · 本地客户端联调态 · CI 发布态)。见 [§9.0.54](../journal/90-push-windows.md)。

## 4. 照抄的分层缺陷

| 项 | 说明 | 出处 |
|---|---|---|
| **敌人 EXP/DUELPOINT 判定树** | 三值构成一棵树(`DUELPOINT<=0` 才给 EXP · `EXP==-1` 是"不覆盖"哨兵)⇒ ⚠️ **拆开移植会得到"看起来对"的错经验值** | [§9.0.40](../journal/12-encounter.md) · `11` DR-DT15 |
| **捕获成功删除全部条件道具** | 全删而非逐删(`_CAPTURE_FREES` 开)—— 已被**原开发者显式决策过** | `11` DR-BT10 · [§9.0.50](../journal/14-item.md) |
| **职业路径的互斥循环** | `:5195` 有循环,只是 11 种在循环前 `return 1` 绕过 ⇒ 照抄这个形状 | [§9.0.55](../journal/15-status.md) |
